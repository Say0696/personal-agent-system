# Document Fidelity

Use the user's local document profile when available. This public skill contains the workflow, not personal formatting preferences.

1. Inspect the reference before editing: page size and margins, fonts, sizes, paragraph spacing, indents, headings, tables, headers/footers, numbering, page breaks, and embedded objects.
2. Treat observed layout as a constraint. Copy the structure and styles before introducing new design choices.
3. Make the smallest change that satisfies the request. Do not “improve” or reflow unrelated sections.
4. Render the result when visual layout matters and compare representative pages with the reference. Structural parsing alone is not visual proof.
5. Record any unavailable font, conversion, rendering, or fidelity limitation explicitly.

Keep user-specific examples and formatting rules in local memory, never in this public repository.
